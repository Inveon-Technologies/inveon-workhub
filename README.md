## 🚀 Quick Start Guide

### Prerequisites
* **Node.js**: v18.0.0 or higher
* **npm**: v9.0.0 or higher

### Installation & Launch
```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Open in your browser
# Navigate to: http://localhost:3000
```

### Production Build
```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```

## 🏛 Platform Architecture & Features

### 1. Global Application Shell
* **Header**: Transparent Inveon brand logo, global command palette (`Ctrl + K`), notification drawer, app switcher launcher, and user profile drawer with secure sign-out.
* **Floating Navigation Rail**: Compact, modern icon-based floating dock connecting all workspaces.
* **Ambient Lighting & Aesthetics**: Architectural gradient meshes and micro-animations.

### 2. All 16 Enterprise PRD Workspaces
1. **People & HRMS**: Workforce directory, organization hierarchy tree, and department rosters.
2. **Work & Tasks**: Kanban sprint boards, task workflows, and priority management.
3. **Project Portfolio**: Multi-project roadmaps, milestone tracking, and health metrics.
4. **Time & Attendance**: Shift punch check-in/out, biometric logs, and exception regularization.
5. **Leave & Time-Off**: Leave balance cards, calendar view, and approval workflows.
6. **Payroll & Compensation**: Monthly run automation, tax deductions, and encrypted payslip vault.
7. **Recruitment & ATS**: 8-stage candidate pipeline, job requisitions, and interview scheduling.
8. **OKRs & Performance**: Goal alignment, quarterly key results, and 360° reviews.
9. **Onboarding Lifecycle**: Pre-boarding checklists, IT provisioning, and buddy assignments.
10. **Document Vault**: Encrypted repository for employment contracts, NDAs, and policies.
11. **Growth & LMS**: Skill academy courses, certifications, and learning analytics.
12. **Calendar & Meetings**: Room bookings, town halls, and 1-on-1 meeting scheduler.
13. **Chat & Channels**: Topic-based team channels, direct chats, and messaging.
14. **Reports & Analytics**: Visual charts, headcount metrics, and PDF/CSV export engine.
15. **Organisation Settings**: Shifts, company holidays, 2FA security, and branding controls.
16. **Security & Governance**: Role-based access control (RBAC), SSO, and audit trails.
